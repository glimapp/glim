# 从自己的文件开始使用 Glim

[English](user-guide.md) · **简体中文** · [文档目录](README.zh-CN.md)

Glim 是 Mac 上的文件查看工作区。你可以是来读合同的职场人士、查资料的学生，也可以是检查数据和代码的开发者。直接打开已有文件即可；想了解适合自己的用法，先看[场景专题](topics.zh-CN.md)。

## 先打开一份文件，或一整个文件夹

安装步骤见[下载与安装](../README.zh-CN.md#下载与安装)。

- ⌘O 打开文件，⌘⇧O 打开文件夹。文件夹会成为一个工作区，可以从左侧逐个打开相关文件。
- “添加文件夹到工作区”把另一份资料加入当前工作区。侧栏也可以保留多个工作区，切换时各自的标签保留。
- 主页提供打开文件、打开工作区和新建文件，也列出最近的工作区。工作区改名只改变显示名称，不改磁盘目录名。
- 标题栏搜索按文件名或路径找工作区里的文件，不搜索文件正文。源码编辑器中的查找用于查当前文本。

## 打开远端文件夹

点击主页“打开工作区…”旁的箭头，添加 SSH 连接或选择已保存的连接。“设置 → 文件 → SSH 连接”可管理多个连接并测试连接。填写主机，也可使用 SSH 配置别名；表单依次显示名称、主机与端口、用户名、私钥，可选项留空时沿用 Mac 的 SSH 配置与 agent。测试连接时通过覆盖层显示状态，成功后两秒自动消失，失败信息可关闭后继续修改。在连接管理中保存后，直接返回更新后的连接列表；主机与认证设置未变时保留测试成功的会话。绿点表示已有连接会话，仅保存配置不会建立连接。需要时 OpenSSH 会询问主机信任、密码或密钥口令。

选择连接后，输入路径或浏览目录（默认包含隐藏目录），在目标路径右侧确认“打开文件夹”。最近使用的远端工作区可以直接重连。文件按需下载并保持只读，文本也不例外。地球图标标识远端工作区，文件标签只保留文件类型图标，悬停标签可查看主机与只读状态。目录浏览页取消后返回连接列表；向当前远端工作区添加文件夹时则关闭弹窗。使用既有的刷新操作刷新或重连；远端修改不自动监听。下载使用本地临时存储，大文件需下载完成再预览；目录形式的文档包和完整 HTML 网站不做镜像。需要一致的 SQLite 视图时，请打开已经停止变化的数据库副本。

## 保留正在看的文件

点击文件后会留下标签，打开下一份文件时可以再切回来。同一个文件再次打开，会激活已有标签或窗口。后退／前进用于回到先前打开的文件。

标签右键菜单可以在访达中定位、复制路径，或移到独立窗口；也可将标签拖出原窗口。收起侧栏能腾出空间，点击窄栏中的文件夹图标可重新展开。

⌘W 关闭当前标签或空窗口，⌘⇧W 关闭当前窗口。关闭最后一个窗口后应用仍运行，⌘Q 才是退出 Glim。未保存内容会经过保存确认。

## 按内容选择查看方式

| 你打开的内容 | 常用操作 |
| --- | --- |
| 合同、报告和演示文稿 | PDF 翻页、选字和缩放；Word 切换阅读模式／原始版式；支持的文稿可全屏放映 |
| 表格与数据 | Excel 切换工作表、分页；CSV/TSV 按表格查看；JSON 展开数据树 |
| 笔记与技术文档 | Markdown 切换预览／原文，查看公式和图表；普通任务清单可直接勾选并保存 |
| 图片与字体 | 缩放、复制图片；支持的位图可提取文字；字体可输入示例文字 |
| 电子书与漫画 | 目录、章节或漫画页、字号和行距、书签和进度 |
| 音视频 | 播放／暂停，也可按文件夹顺序或随机播放 |
| 导图和结构化数据 | XMind 展开／折叠；支持的数据可切换交互图 |

阅读操作会出现在工具栏或内容右键菜单。部分悬浮工具栏在鼠标停到内容底部附近时才显示。文件全屏可以让当前内容铺满阅读区域，Escape 返回工作区。快捷键帮助在“设置 → 键盘快捷键”。

不同格式的操作并不完全相同。详见[场景专题](topics.zh-CN.md)和[格式兼容表](file-format-support.zh-CN.md)。

## 做一点文本修改

普通 UTF-8 文本支持输入、选择、撤销重做和 ⌘S 保存。已有文件在停止输入片刻后自动保存，直接写回原文件。阅读配置和共享文件时，请留意这一行为。磁盘内容已被其他程序修改时，Glim 保留编辑器中的未保存内容并提示冲突。

⌘N 新建未命名笔记。第一次 ⌘S 时选择位置和名称，之后自动保存。改扩展名不会把文本转换成 PDF 或 Office 文档。

大文本或超长行使用可编辑分页，翻页时按提示先保存当前页。表格、数据树、数据库、图片和办公预览保持只读；可编辑内容通过原文入口修改。关闭未保存内容时可选择保存、不保存或取消，保存失败后保留打开状态。

## 查看数据库或解开资料包

打开 SQLite 主库文件，选择表或视图，再筛选、排序和翻页。双击单元格可读完整值。Glim 创建独立只读快照，包含可用的关联 WAL/journal，不修改或 checkpoint 原库。不支持加密数据库和任意写入 SQL。

ZIP、TAR 及其压缩变体、7z、RAR 等支持的归档共用目录浏览器；进入文件夹可查看条目名称和大小，解压后生成独立新目录并作为新工作区打开，不覆盖已有目录，支持取消。独立 GZ/BZ2/XZ/LZ4/Zstandard 压缩流显示为一个解压后文件；加密、分卷及不支持的编解码变体会报告错误。

## 下次打开时继续

普通启动可以恢复保存的窗口、工作区、文件标签、顺序和支持的预览模式。最近工作区也可在当前或新窗口打开。文件已移动或删除时，恢复的标签会显示不可用。

通用滚动位置、光标位置和媒体播放时间尚不完整恢复；恢复的媒体保持暂停。电子书单独保存阅读进度和书签。

未命名笔记使用本地检查点恢复，尚未写入检查点的内容仍可能丢失，重要笔记应保存为文件。应用更新另有一次性重启检查点，见[更新与恢复](updates.zh-CN.md)。会话记录和应用备份都不能代替用户文件备份。

## 设置与求助

设置提供外观、语言、默认文件关联、检查更新、快捷键和使用统计开关。将 Glim 设为某类文件的默认应用后，访达打开该类文件可能直接进入 Glim。

联网与本地记录见[隐私说明](privacy.zh-CN.md)。遇到打不开、预览差异或保存问题，先看[常见问题](faq.zh-CN.md)，再通过[问题反馈](https://github.com/glimapp/glim/issues/new?template=bug_report.yml)提供版本、Mac 类型、操作步骤和可公开的脱敏样例。日志可能有本地路径，分享前请检查。
