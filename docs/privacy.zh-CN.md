# 隐私与联网说明

[English](privacy.md) · **简体中文** · [文档目录](README.zh-CN.md)

## 我的文件在哪里打开？

文档、图片、数据和代码在本机处理，无需上传到托管查看服务。SQLite 在本机创建私有快照；部分文档转换、图片解码和媒体播放也会产生临时资源。

Glim 在本机保存偏好、最近工作区、路径、窗口与文件标签、草稿恢复和电子书进度。当前主要存放在 `~/Library/Application Support/Glim/glim.sqlite3`，应用备份和日志等另存为文件。这些本地记录可能包含路径或草稿正文，不能将“统计不上传正文”理解为“本机不保存正文”。

## 哪些操作可能联网？

| 内容或操作 | 行为 |
| --- | --- |
| Markdown 远程图片 | 读取文档里的远程图片地址并下载，目标服务器可能收到请求 |
| HTML 网页预览 | 可运行 CSS、JavaScript，并加载网络内容；行为取决于页面 |
| 点击外部链接 | 按所选操作打开对应地址 |
| 应用更新 | 根据更新模式检查发布信息，下载和验证安装包 |
| 使用统计 | 仅在该选项开启时发送功能使用和前台活动记录 |
| 错误诊断 | 仅在这个独立选项开启时发送脱敏故障与 panic 报告 |

电子书不加载远程图片或执行活动内容；离线图表引擎随应用提供。关闭更新、统计与诊断不会关闭 HTML 或 Markdown 自身的网络内容。来源不明的 HTML 应先按普通代码文件谨慎检查。

## 如何选择发送哪些信息？

设置 → 帮助改进 Glim 提供独立的**错误诊断**和**使用统计**开关。没有记录过选择的安装，会先提示选择仅错误诊断、两项都开启或暂不发送。错误诊断帮助开发者定位故障、修复崩溃，可在不发送功能使用记录的情况下单独开启。两项都可随时修改；拒绝发送不会限制文件查看或编辑。

旧版总开关有明确保存的选择时，两个新开关均继承该选择；没有保存过选择的旧安装与新安装一样先提示。偏好无法读取时两项都关闭。两个选项一起保存，保存失败会在设置中提示并提供重试；当前选择仍在本次运行中生效。

## 使用统计会发送什么？

启用后会收集功能操作、固定分类的文件格式、成功／失败、操作耗时与前台停留片段。系统资料包含版本、架构与语言，不再常规采集进程资源或硬件配置。滚动和快捷键记录操作指标，不记录输入正文。

统计使用随机安装标识关联同一安装的使用情况，因此它可关联跨会话记录。不会采集账号、硬件序列号、用户名或设备名称；不会上传文档正文、文件名、完整路径、搜索词、数据库表列名、URL、识别出的文字或原始日志／错误文本。

统计口径是**开启使用统计的活跃安装数**，不能代表全部活跃用户；同一个人可能有多个安装。关闭统计、断网或发送失败后的使用情况属于未知，缺少报告不能认定为流失。关闭使用统计后没有隐藏的活跃心跳。随机标识可关联跨会话记录，属于不含身份信息的假名化标识，不能承诺完全不可关联。联网时接收服务仍能看到来源 IP，尽管 Glim 不在遥测载荷中添加 IP 地址。

## 错误诊断会发送什么？

诊断包含错误分类、程序源码位置、组件／操作、脱敏指纹、错误码、版本和有限的应用栈符号；重复错误合并上报。不发送文档正文、文件名、路径或错误原文。panic 报告尽力发送，突然终止可能导致来不及上报。

只开启错误诊断时，不发送使用事件、活跃记录或持久安装标识；使用临时会话 ID 关联同一上报会话中的故障。两项都开启时，使用统计导出中也包含诊断事件，用于解释操作失败。

关闭任一选项会立即停止对应采集和发送。改变选择会清空待发送数据并取消在途遥测任务；重新开启不会补发关闭期间的记录。两项都关闭后，不启动遥测后台任务，也不请求远程遥测配置。这不影响独立配置的更新检查或文档联网内容，也不会删除服务端已收到的报告。详细字段和解释见[统计技术说明](telemetry.zh-CN.md)。

## 我需要备份什么？

文本修改会自动保存到原文件。重要资料仍需自行备份。应用更新备份保存的是 Glim 应用包，不包含用户文档、偏好和草稿的完整备份。

反馈问题时仅分享可以公开的脱敏样例。完整诊断保留本机，日志可能包含路径；分享前请检查。安全漏洞使用[私密报告入口](../SECURITY.md#中文说明)。
