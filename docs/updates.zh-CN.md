# 更新与恢复

[English](updates.md) · **简体中文** · [文档目录](README.zh-CN.md)

## 怎么更新？

从 Glim 菜单或设置中检查更新。检查完成后会显示状态；发现可用版本时打开更新窗口，查看更新说明后按界面操作。遇到错误时，按提示重试，或前往[发布页](https://github.com/glimapp/glim/releases/latest)手动下载。未配置更新器的本地构建使用手动下载入口。

当前提供仅手动、检查提醒和自动更新模式。自动更新默认允许后台下载并验证，在正常退出或明确选择重启时安装，尊重已有偏好；不会为了安装而强制打断编辑或自动填写管理员凭据。

## 我正在编辑的内容怎么办？

安装前会检查所有已登记工作空间的未保存内容、保存和文件加载，准备应用备份及一次性会话检查点。工作未完成或记录失败时会阻止安装重启并提示原因。仍建议先保存重要文件。

更新重启可恢复支持的工作空间、文件和播放列表标签、顺序及预览模式。媒体保持暂停，通用滚动位置和播放时间尚不完整恢复。检查点不保存未保存正文；草稿使用独立恢复机制。

## 备份能恢复什么？

更新前保留一组已验证的 Glim 应用包 ZIP 和校验回执，位于 `~/Library/Application Support/Glim/UpdateBackups/`。它用于手动恢复应用版本，不包含用户文档和偏好的完整备份。新版本崩溃后不会自动按健康检查降级。

## 更新失败会怎样？

离线、签名不符、包损坏或不兼容时不会安装该包。取消授权、其他运行副本、只读位置和安装权限也可能阻止替换；根据实际错误处理，不需要关闭系统安全保护。更新签名验证与 Apple 公证不同，目前仍需遵循[首次安装说明](../README.zh-CN.md#macos)。

维护者需要了解签名、恢复与安装细节时，参见[更新实现](auto-update-design.zh-CN.md)和[发布流程](releasing.zh-CN.md)。
