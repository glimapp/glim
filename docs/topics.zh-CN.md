# 按你的使用场景了解 Glim

[English](topics.md) · **简体中文** · [文档目录](README.zh-CN.md)

Glim 适合在 Mac 上查看混合类型的本地文件，也能做基础文本修改。你可以按自己的事情选专题；同一份 PDF、图片或数据可以属于多个专题。专题是使用入口，所有文件仍在同一个工作空间中打开。

<a id="office"></a>

## 办公文件

适合经常接收合同、报告、表格和演示文稿的人。把同一件事的资料放在一个文件夹里，打开后在标签间来回查看。

PDF 可翻页、缩放、选字，也可以全屏放映；Word 可切换阅读模式和原始版式；Excel 可切换工作表、分页查看；PowerPoint 和 Keynote 可调用系统全屏演示。支持的文档还提供复制预览文字、识别图片文字。

常见文件：PDF、DOC/DOCX、RTF、XLS/XLSX/XLSM、PPT/PPTX、Pages、Numbers、Keynote。

当前边界：办公文档预览只读。复杂排版、图表和嵌入对象可能有差异；Excel 不重算公式，部分预览省略绘图。系统预览器决定部分文档的显示与演示能力。ODT/ODS/ODP 仅提供容器目录和部分文本。

<a id="reading"></a>

## 阅读与学习

适合学生、研究者，以及想在 Mac 上读书和看资料的人。一本书、课程 PDF 和自己的笔记可以放在一起。

电子书可以按目录切换章节，调整字号、行距和纸张，保存书签与阅读进度；漫画按页查看。PDF 使用独立的文档阅读器。笔记可用 Markdown 或普通文本。

常见文件：EPUB、FB2/FB2 ZIP、CBZ、PDF、TXT、Markdown。

当前边界：电子书不完整还原出版者 CSS 和固定版式，不支持 DRM EPUB、MOBI/AZW。电子书进度与通用文档滚动位置分别管理。

<a id="images"></a>

## 图片与设计素材

适合查看照片、设计交付物、截图和字体的人。打开素材文件夹，逐个确认内容。

查看常见位图、GIF 动画、多页 TIFF 和 SVG；复制图片，在支持的位图中提取文字。字体可以查看字形、输入自己的示例文字，无需安装。

常见文件：PNG、JPEG、WebP、GIF、TIFF、SVG、EXR/HDR、QOI，以及 TTF/OTF/TTC 等。

当前边界：预览只读；EXR/HDR 转为 SDR 显示。大图可能使用缩放解码，原尺寸缩放不保证原分辨率解码。文字识别可能有误，SVG 不提供图片 OCR，也不加载外部文件资源。BDF 仅提供基础字形预览。

<a id="media"></a>

## 音视频与字幕

适合查看录音、课程视频、拍摄素材和字幕的用户，也适合内容创作者整理本地素材。

在标签中播放音视频，按文件夹顺序或随机播放；字幕可按时间戳阅读，也可以编辑原文。

常见文件：MP3、MP4、MOV、M4A、WAV、FLAC 等，部分 MKV；SRT、VTT。

当前边界：媒体解码取决于 macOS。MKV 仅支持 H.264/AAC-LC 的重新封装路径，不支持其他 MKV 编码及内嵌字幕。独立字幕不与视频同步；播放列表只枚举文件夹直接子文件，恢复后暂停。

<a id="notes"></a>

## 笔记与思维导图

适合写说明、整理课程笔记、需求和方案的人。用文本记录，再查看相关导图和图表。

Markdown 支持表格、公式、图表和任务清单，普通文档中的任务可直接勾选并保存。XMind 可以切换工作表、折叠主题、缩放和查看节点详情。OPML 可按大纲展开。

常见文件：Markdown、TXT、XMind、OPML、D2、Pikchr、Vega 图表，以及 AsciiDoc/Org/RST 基础预览。

当前边界：XMind 只读，使用统一布局，不还原原始位置、图片和附件。图表语法有兼容范围，不加载外部导入或资源。普通文本修改会自动写回原文件。

<a id="data"></a>

## 表格与结构化数据

适合运营、分析师、产品经理和开发者，快速确认导出数据、接口响应或配置里写了什么。

CSV/TSV 按表格阅读，可查看完整单元格；JSON 系列按树展开。支持的 JSON、YAML、CSV/TSV 和 XML 还能切换交互图，展开节点查看结构。

常见文件：CSV/TSV、JSON/JSONC/JSON5/JSONL、YAML、XML；办公表格见办公专题。

当前边界：表格、树和交互图保持只读；修改通过可编辑原文完成。交互图是另一种查看方式，复杂数据可能退回原文；不包含数据分析、Schema 生成或图片导出。

<a id="database"></a>

## 数据库查看

适合开发者、分析师和技术支持，查看应用导出的本地数据库，或排查一条记录。

打开 SQLite 主文件，选择表或视图，查看结构和 SQL 定义，搜索全部记录的字段、排序和分页；双击查看完整值。

常见文件：SQLite、SQLite3、DB、DB3，以及可通过文件头识别的 SQLite 文件。

当前边界：查看使用独立只读快照，关联 WAL/journal 通过主库处理；不写入原库，不执行任意写入 SQL。暂不支持加密数据库，也不连接 MySQL、PostgreSQL 等远程数据库。

<a id="developer"></a>

## 开发者工作台

适合阅读项目、排查日志、检查配置和撰写技术说明的开发者。

源码高亮、折叠、搜索和概览，普通 UTF-8 文本基础编辑；HTML 可查看网页效果与原文，Markdown 可查看公式和架构图。可检查可执行文件的基础元数据。

常见文件：常见编程语言、HTML/CSS/JS、Shell、配置、日志、Markdown、Mach-O/ELF/PE。

当前边界：不编译、调试或执行源码，不提供 LSP 或插件。可执行文件只读检查，不运行或反编译。HTML 预览会执行页面 JavaScript 并可能联网，请了解文件来源。

<a id="graphics"></a>

## 2D 图形与 3D 模型

适合确认矢量素材、技术图和三维网格内容的人。二维查看与三维速览的能力分别说明。

二维内容可查看 SVG、基础 draw.io 图、流程图和架构图；三维文件提供 OBJ/STL 静态网格投影。

常见文件：SVG、draw.io、Markdown 图表、D2、Pikchr、OBJ、STL。

当前边界：当前三维没有交互旋转、材质和纹理；draw.io 的自定义图形、嵌入图片和精确布线可能简化或省略。没有承诺 DWG/DXF、STEP 等工程格式支持。

<a id="gis"></a>

## GIS 与轨迹数据

适合地图开发者、地理数据使用者和需要检查轨迹文件的人。

GeoJSON 可展开要素与属性；GPX/KML 按坐标表查看，并保留 XML 原文。用于确认文件里有什么字段和坐标。

常见文件：GeoJSON、GPX、KML。

当前边界：当前没有地图底图、轨迹地图绘制、空间分析和坐标转换。GeoJSON 使用数据树，GPX/KML 使用坐标表；不承诺 Shapefile 或 GeoTIFF 的 GIS 专用能力。

<a id="research"></a>

## AI 与科研文件

适合需要先确认模型文件、数值文件或 Notebook 内容的 AI 开发者和研究者。

safetensors 展示张量名称、形状、精度、参数量和元数据；NPY 展示头部及支持类型的数值；Notebook 按 JSON 结构阅读。

常见文件：safetensors、NPY、Notebook；也可一起查看 CSV、PDF 和研究笔记。

当前边界：不运行模型、Notebook 或 pickle。NPY 数值类型支持有限，其他类型保留元数据；GGUF、ONNX、NPZ 阅读器尚待实现。

<a id="archives"></a>

## 压缩包与资料交接

适合收到项目资料包、备份或压缩日志后，想先看看里面有什么的人。

ZIP 可浏览目录和条目大小，也可解压到独立的新目录并作为新工作空间打开。TAR 可查看条目；GZ/BZ2/XZ 可按需解压成原文分页阅读。

常见文件：ZIP、TAR、GZ、BZ2、XZ。

当前边界：ZIP 解压会创建新文件，保留原包，不覆盖已有目录；可取消。TAR 当前仅查看目录。压缩文本阅读与通用压缩包管理的能力不同。

## 从一个真实的文件夹开始

办公资料、课程资料、设计交付或代码项目，都可以直接用作工作空间。文件夹列表用来找文件，标签用来保留正在看的内容。你不需要先给文件贴专题标签。具体操作见[使用指南](user-guide.zh-CN.md)，需要核对某种文件时查[格式与兼容范围](file-format-support.zh-CN.md)。
