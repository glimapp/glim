# 阅读器资源与渲染

[English](reader-resources.md) · **简体中文** · [架构](architecture.zh-CN.md)

Glim 采用格式专属表示，复用任务准入与资源所有权机制。文本使用分页和语法范围，数据库使用查询窗口，工作簿使用磁盘索引，书籍使用章节，图片使用预算内预览，原生文档保留系统控制器。场景组合已有阅读能力，不要求通用 AST 或全部转换为 Markdown。

## 资源所有权

`glim-core::resources` 实现无 UI／I/O 的资源池，`glim-services::resources::pool()` 持有进程级实例。RAII 租约的克隆共享同一笔记账，最后一个所有者释放时扣减；调整大小更新原记录。计数器提供常数时间快照，不是堆内存测量。

| 类别 | 已接入的所有者 | 释放／重建 |
| --- | --- | --- |
| 状态 | 编辑会话当前文本与保存基线，OPML／XMind 载荷和图结构展开索引、书籍目录与内嵌资源、原生准备请求及其索引元数据的估算字节 | 跟随会话，不参与缓存淘汰 |
| 工作缓冲 | CSV／JSON／交互图投影和输入快照、SQLite 当前网格、分页文本／行索引、缩略图几何、书籍章节 HTML／锚点和准备好的 PNG；静态预览页／书籍图片／内联图片／GIF 显示和预解码像素，GIF 画布、恢复画布及行缓冲；原生图片与复制／OCR 共用的像素、待发布剪贴板数据 | 取消后释放工作数据；已显示图片延迟到窗口可用时清理图集 |
| 缓存 | 服务层图表 PNG 复用、视图层图表图片／错误 | 共享预算，先回收后台项，再按同类最近访问顺序回收 |

`CachedResource` 保留可能变空的键，阅读器将空项视为未命中，并从原始内容重建。调用者持有 `ResourceValue` 期间固定对应缓存；图表元素绘制期间保留该所有权。回收在资源池锁外执行，跳过正忙或被固定的项。共享缓存目标只在 `assets/reader-limits.json` 定义，原有编码／解码／键值局部预算继续生效。分配触发回收，显式 `trim` 可以回收刚解除固定的项；仍被使用的资源及刚发布的结果可暂时超过目标；新结果在初次回收期间保留，防止缓存压力使它尚未发布就被丢弃。

`reserve_working(minimum, desired)` 在锁内原子预留共享工作预算，已有工作资源的记账也占用可用容量。容量不足时授予较小窗口；连最小窗口都无法容纳时，返回可重试的资源压力错误，不占着工作线程等待。预留只能缩小，扩大必须重新准入。文本／十六进制分页在分配输入、显示文本和行范围前预留，按实际容量调整字节窗口，预留随结果发布与显示一直存活。准备结果同时持有行索引和最宽行位置，视图构造不再扫描页面。隐藏只读页同时释放缓冲和预留；替换失败保留旧的可读页，可通过“重试”重新加载当前页。可编辑页把基线与索引转交受保护状态记账。逐页字节偏移仍能访问完整源，跨窗口的 UTF-8 字符保持完整。

`TextRowsBuilder` 在分配前为单元格、行向量及外层向量扩容峰值准入，不可变的 `TextRows` 结果在交给 UI 后继续持有预留。CSV／TSV、地理坐标页和 SQLite 网格共用该缓冲。CSV 解析另为固定版本解析器的当前记录、字节／字符串表头和输入缓冲预留保守工作区，读取更多输入前原子扩容。CSV 和地理坐标页遇到压力可发布已完成的行，下一页从紧接的行继续；首行也无法容纳时返回错误，完整源码仍可访问。SQLite 的页偏移固定，因此整次请求失败，不发布会导致下一页跳行的短页。其有损文本转换另有有界临时预留；SQLite 引擎／缓存和地理 XML 解析暂存仍未完整接入。表格重试控件复用已有加载路径。

CSV／地理数据与 JSON 源码投影共用准入快照 `TextSnapshot`：先预留预算，再直接复制借用的 Rope 块，不创建中间 `SharedString` 或第二份工作线程输入。输入不变时直接复用已有所有者，无需再次申请。准入失败保留编辑器，可返回源码模式。所有工作线程／视图所有者释放前，快照预留始终存活。

JSON／JSONC／JSON5／JSONL 输出节点及交互图中间节点使用 `structured::TreeBuilder`。节点字符串、节点槽位和子节点索引均在分配前准入，包括向量替换时的新旧缓冲；压力导致整次准备失败，不发布残缺树。构建期间复用按需扩大的预留窗口，交付时收缩到驻留容量，避免每个节点都锁定共享资源池。不可变结果持有预留直到释放。JSON 视图在发布前另行预留可见行和遍历数组，折叠时复用数组；展开状态采用每节点一字节的准入数组，隐藏后仍占用共享工作预算。隐藏释放节点及遍历／显示数组，保留折叠／滚动状态和用于重建的共享输入。加载适配层为准备／发布错误提供重试。JSONC 标准化副本也提前准入，并按有界字节间隔检查取消；JSONL 在记录间、节点转换在节点间检查。整次解析器调用在前后检查，执行期间仍不可抢占。解析器 `Value` 树、JSON5 内部及临时格式化尚未完整准入。

结构化交互图在分配前为遍历数组和完整最终载荷预留预算。输出字符串和索引向量使用精确容量，包含对象分组后的完整备注，避免临时字段数组与格式化字符串副本。构建期间保留已准入的输入树；`PreparedGraph` 在工作线程到视图的交接中持续持有最终预留，不再重复计入状态资源。压力或取消释放未完成结果，完整源码仍可访问。XMind 解析、图布局和解析器内部仍需分别接入准入。

其他生产者仍使用不限制增长的 `track`／`resize`；其记账会减少预留可用容量，但自身仍可能超过目标。将这些路径接入准入、对活动阅读器的可重建资源实施压力回收仍待完成。这是已接入所有者的记账，不是进程内存硬上限。文本容量／撤销历史、全部驻留投影、书籍 HTML 解析树、GPUI 资源／图集缓存、ImageIO、WebKit、Quick Look、解析器内部和辅助进程分配尚未完整覆盖。图表解码字节为估算值；不可将这些计数与系统 footprint／Metal 计数相加，口径和覆盖有重叠。`resource_sample` 沿用现有统计授权，记录状态、工作缓冲、缓存、缓存目标及回收次数。

CSV／JSON 投影在切换到源码或标签隐藏时取消任务并释放派生行／节点，保留重建输入和必要的查询／折叠状态。重新激活只重建当前投影；原编辑会话不参与释放。结构化交互图关闭时释放图实体，下次明确打开时重新准备。

SQLite 隐藏时取消分页、计数、详情和快照刷新任务，释放当前网格单元格，保留私有磁盘快照、筛选／排序／页码、滚动位置和已打开的只读详情。返回时重建当前页，只重启尚未完成的计数；隐藏期间收到的文件刷新延迟到激活后处理。恢复中的刷新失败时，使用仍保留的旧快照重建网格并报告错误。隐藏后收到的已排队筛选变化仍更新保留的查询。已打开详情沿用编辑状态的资源所有权，可选缩略图几何随阅读器激活状态释放／重建；取消中的详情请求不自动重发。

书籍隐藏时取消章节加载，释放当前章节 HTML 视图、锚点和图片实体，保留目录、阅读偏好、章节与位置。有文字选区时保留 HTML 视图和章节编码图片，避免返回后丢失选区；解码图片仍释放。恢复不会重新保存默认偏好；初次加载中断会重新读取已有偏好。写入阅读位置的任务独立于显示生命周期。书籍分页后备保留同一分页实体和源句柄，只释放可重建的文本／行索引；其他只读分页采用同一机制。可编辑页保留编辑会话和保存基线。

`media::PreparedImage` 由静态预览页和书籍共用。编码 PNG 保留原有记账；静态、书籍与内联 PNG 解码统一经过 `services::media::raster`，先只读取固定尺寸头，再为源像素表示、RGBA 转换和策略指定的解码器工作空间预留预算。结果 `RasterFrame` 同时持有像素和剩余工作预留，BGRA 转换及 GPUI 交付直接移动所有权，不复制或重新记账。解码使用已有调度器，像素直接绘制，不进入 GPUI 的隐式图片资源缓存；隐藏、换页或销毁时取消任务，窗口图集延迟清理期间继续持有预留。静态预览页保留编码 PNG 以支持恢复和复制，书籍离开章节时释放编码数据并在需要时重读章节。独立预览解码失败后提供重试；内联图片在重新激活或明确刷新时重试。

GIF 在创建画布前，为画布／恢复缓冲及 RGBA 转换器持有的索引行分配预留预算。选择分辨率时给源扫描行、两批预取帧和当前显示帧留出空间；输出帧和源扫描行另行逐次准入。较小额度降低预览分辨率，不因源尺寸拒绝文件。直接最近邻采样只写最终缓冲，替代会生成整张全宽浮点中间图的图片库路径。准入失败保留待处理帧头，重试不会跳过该帧；检测动画结束无需分配下一帧。压力下已完成的预取前缀仍可显示。独立动画错误提供重试，开始重试前保留最后可读帧。销毁解码器会释放其工作状态，显示／预取帧仍各自持有预留。

编码预览生成、SVG 缩略图中间缓冲、GIF 元数据／LZW 内部和原生辅助进程分配尚未全部准入，不能把上述像素／扫描行所有权覆盖解释为进程内存上限。

原生准备结果保留磁盘索引、转换文件及其清理所有权，记账仅覆盖驻留配置与元数据，不把磁盘文件大小当成内存。隐藏标签取消尚未完成的原生准备；已经建立的系统控制器仍保留自身导航状态。菜单遮挡只隐藏预览。`native/ReaderResources.swift` 让 ImageIO 结果发布、显示、Live Text、OCR 和复制共享不可变图片所有者，通过线程安全的数字句柄持有 Rust 资源池租约，不依赖统计授权。像素按实际行跨度乘高度记账，消费者仍在执行时，取消不会提前释放其租约。Office 内嵌图片提取和已交付的 PDF／Word OCR 快照采用同一所有权；复制结果的字节租约保留到剪贴板发布结束。框架内部、编码中间缓冲、剪贴板服务及独立辅助进程的内存仍不在此账本内，共享字节准入尚未完成。

## 可见工作与取消

共享调度器分文档、投影、解码、原生准备和图表五个通道。每类优先级保持 FIFO，以视口、交互、视口、后台的加权周期推进，跳过空队列。等待准入不占后台线程，真正执行的工作直到退出才释放配额，包括 UI 已取消的情况。运行中的 SDK／解析调用不被抢占；持有配额时不得同步等待形成依赖环的另一份配额。

Markdown 虚拟图片子树记录布局／绘制实际请求。每帧结束后，未被请求的图片停用：静态图片任务和 GIF 下载／播放取消，解码帧释放，重新进入时重建。GIF 构造器不下载屏外 URL；已下载临时文件可在阅读器存活期间复用。重新激活时 GIF 从头播放，有限循环动画也遵守此规则。工具包预布局可能请求邻近图片，所以这是渲染需求，不等同于逐像素可见性。嵌套提示块的图片及浏览器／系统视图保留自身加载路径。

图表／公式节点按视口需求组成有界批次，完成后更新布局而不重解析全文。服务层 PNG 复用键包含图表类型、完整源和栅格边长，持久化结果缓存作为进程内存缓存的后备。回收不丢弃原始内容。离线引擎随包分发，按需加载模块，单个结果失败不终止其他类型。

## 大文件路径

UTF-8 编辑采用分页、固定缓冲流式复制和原子保存。XLSX／XLSM 建立磁盘 SQLite 单元格索引，展示页保留缓存值、样式和合并，不重算公式、不运行宏。书籍按章节与成员访问，必要时提供完整文本／字节成员后备。CSV／SQLite 单元格和地理坐标按窗口读取。压缩包流式读取内容，压缩流按需重建解码器。GIF 使用有界画布和预览批次，普通图片采用缩放预览，尚非原始分辨率分块。远程图片流式落盘，HTML 经本地资源工作线程读取，DOM／脚本内存由 WebKit 管理。超出结构化投影预算时保留完整源分页。

文件总大小不作为准入门槛。[生成的策略清单](reader-limits.zh-CN.md) 说明工作缓冲、分页和后备行为。ZIP 中央目录、SQLite 表达式、原生转换等仍受库／系统约束，部分索引须准备后才显示首屏。修改数值后运行 `python3 scripts/generate-reader-limits.py --docs`。

## 解析测量

在 macOS 运行 `cargo bench -p glim-app --bench markdown_edit --locked`。基准向标准输出写 JSON；测量结果连同机器、工具链和提交信息保存到仓库外。它调用生产 TextView 的解析／更新函数，在同一优化构建内比较全文解析基线与块复用路径，并交替执行顺序。计时包含基线克隆、编辑定位、解析、源码范围调整与结果构造；请求字符串准备和语义对比在计时之外。结果必须与全文解析一致才会报告样本。

固定夹具包含 100、1,000 和 5,000 段正文，带中文、行内代码和链接；头部／中部／尾部的插入与删除各重复四轮。小型夹具覆盖列表、表格、围栏、引用定义、追加、缩进、引用块、Setext 标题、CRLF 和 HTML 边界。输出初次解析耗时、各次更新耗时、送入解析器的字节数（含旧片段复核及被拒绝的复用尝试）与复用块数。全局引用和结构变更按设计走基线路径。复用块数衡量 AST 复用，不代表图片／图表缓存命中率。

该基准只测解析墙钟时间，不测首个可读像素、滚动、输入延迟、进程峰值内存或预览准备；不打开 UI 窗口。剩余复制与块克隆仍随文档大小增长，单个大块和布局重测需要单独测量。测量入口仅在 test-support 构建中启用，不进入普通应用构建。

## 图片测量

在 macOS 运行 `cargo bench -p glim-services --bench raster_memory --locked`。基准在 1 MiB、8 MiB 和 512 MiB 共享工作目标下测量 GIF 初始化与逐帧解码，并保留与 UI 相同的“两批预取＋当前帧”窗口。宽图与常规夹具覆盖自适应分辨率、处置方式、解码器销毁后的帧所有权和完整释放；PNG 夹具测量预算内解码及 BGRA 交付的所有权。夹具生成、像素和所有权对照位于计时之外。JSON 记录调用结束后的驻留字节，不是瞬时分配峰值、进程 RSS 或 GPU 存储；编码夹具和解码器元数据不在此计数内，不能据此宣称资源已全部覆盖。结果和机器／工具链／提交信息保存到仓库外。

## 结构树测量

在 macOS 运行 `cargo bench -p glim-services --bench structured_tree --locked`。基准在同一优化构建内交替执行冻结的准入前解析／投影基线与当前生产准备函数，在计时外比较每个节点的键、完整值、摘要、类型和子节点顺序。夹具覆盖 100／1,000／10,000 条记录、Unicode、重复键、长值及 JSONC、JSON5、JSONL。记录快照复制／匹配和解析／投影耗时，并核对压力拒绝、重试、取消、工作线程输入所有权及完整释放。驻留计数仅覆盖快照与节点；解析器内部、视图布局、首屏、交互延迟及进程内存峰值需另行测量。报告连同环境和源码信息保存在仓库外。

## 源码交互测量

同一个测量构建也可以观察正常工作区启动：设置 `GLIM_MEASURE_STARTUP=1` 启动应用，从标准输出读取 `workspace-startup` JSON。`to_first_frame_submission_ms` 覆盖应用入口到 GPUI 首帧提交，包括正常偏好加载和工作区恢复任务调度。它不包含进入应用前的进程加载和显示器扫描输出，也不表示所有目录或阅读器已完成加载；测量沿用已有用户状态。观察器在首帧提交后或 30 秒后停止，普通构建不包含该入口。

`reader-measurements` 是显式启用的测量 feature，转发 GPUI 已有的 profiler；普通应用构建不包含测量入口。用原生 Cargo 执行 `cargo build -p glim-app --release --features reader-measurements --locked`，保留各版本二进制，再运行 `python3 scripts/measure-source-reader.py --binary /path/to/candidate --baseline-binary /path/to/baseline --output /outside/repository/source-reader.json`。脚本生成含中文的固定纯文本夹具，默认覆盖 1,000／10,000／50,000 行，每组重复三次并交替版本顺序；报告保存二进制和夹具摘要、机器信息、原始样本与中位数／p95。构建工具链和对应源码版本需与报告一同保留。OS 文件缓存未清空，因此不代表冷磁盘打开。

入口创建隔离的真实 GPUI 窗口，使用生产文档任务、`Reader`、编辑器和缩略图；不初始化工作空间、会话恢复、自动保存和统计上传。打开计时从提交文档任务开始，分别记录排队加读取、构造，以及生产源码子树绘制结束后的首个可读视口；测量用于核对正文的额外快照复制也单列耗时。只有编辑器存在有效文字边界与可见行、该内容绘制匹配 GPUI 的 Draw／Present 事件时才记录帧。普通源码在同次同步布局中完成可见行，首段可读与首屏可读共用同一样本；异步预览须另建内容就绪判定。

输入使用 GPUI keystroke 分发和模拟文字输入，交替插入／退格，轮换文档开头、中间和末尾；计时后核对完整正文及脏状态。滚动分发 GPUI wheel 事件并要求视口偏移发生变化。报告区分分发调用的同步耗时、绘制耗时和事件到对应帧提交的延迟；轮询只发现帧，时间戳取自实际绘制／提交事件。它不测物理键盘／触控板延迟、GPU 完成或屏幕扫描输出，也不覆盖工作空间保存开销、预览／原生阅读器、缓存命中率和进程峰值内存。夹具内容在每次运行后核对，测量中发生的编辑不会保存。

编辑会话通过借用的 Rope 与保存基线比较脏状态，直接读取字节长度记账；变化通知和保存确认不再为这两项操作创建全文字符串。长度不同可立即判为有变化，长度相同时仍逐块核对内容。源码缩略图保留共享 Rope 克隆，省去字符串复制；更新比较共同前后缀、跳过共享文本块的字节，只重算受影响行。未共享块仍需逐字节比较，变化时外层块索引仍会重建，因此更新并非严格常量时间。首次构建及完整替换顺序扫描文本块。

行形状使用每块至多 256 行的不可变存储，这是存储结构约束，不限制文档行数。外层索引、块及行缓冲在分配前预留工作额度；旧绘制帧继续持有所有权，未变化块由新旧帧共享。隐藏阅读器释放几何数据，激活时重建。准入失败释放可选形状，保留当前行数导航及编辑器；后续编辑或重新激活会重试。编辑器正文和撤销状态不计入几何额度，沿用独立所有权。

运行 `cargo bench -p glim-app --bench minimap_edit --locked`，比较生产几何算法与原有全文字符串复制／全量几何算法。夹具覆盖 1,000／10,000／50,000 行中文文本，开头／中间／末尾文字及换行插入／删除，重复十二次并交替执行顺序。首次构建单独计时；更新计时包含分配，并持有上一绘制快照。计时外逐行比较全部结果；JSON 记录重算行数及新旧帧并存时的驻留工作字节。它测量计算和已准入驻留存储，不测进程瞬时峰值、UI 帧或文件 I/O。报告及源码／工具链信息保存在仓库外；输入和首屏对照使用上述真实窗口脚本。

## 图表缓存与命中率

`services/markdown_preview/cache::ImageCache` 独立拥有准备好的 PNG 缓存，接收共享资源池与局部缓存预算；生产入口保持进程级互斥访问。键包含引擎类别、完整源和栅格边长。共享池回收后，下次查找清除失效条目并由原准备路径重建；显示消费者仍持有资源时不会提前回收。

`reader/diagrams` 还在进程内跨标签页共享成功的显示预览，以引擎类型和完整源为键。驻留命中直接复用同一图片对象，重开标签页、切回预览或重新解析未变更的图块时，跳过图表任务队列与引擎准备。关闭或隐藏标签页只取消其待完成工作，不清空已完成的共享预览。错误保留在当前视图内，重开或刷新后可重新尝试。共享预览沿用编码、估算解码及键值预算，资源池可回收未被使用的缓存项。这些内存对象不跨应用重启保留。

`services/markdown_preview/disk_cache` 将成功的 PNG、尺寸和公式基线保存到 `~/Library/Caches/Glim/Diagrams`。SHA-256 键包含引擎类型、完整源、栅格边长、内嵌引擎／栅格器构建输入、依赖／策略版本、macOS 构建、架构及字体路径／大小／修改时间指纹。相关输入变化时未命中，旧版本仍参与容量淘汰。文件名和记录仅保存哈希，不保存源码文本或文档路径，但 PNG 包含已渲染的文档内容。目录与原子临时文件创建时仅允许当前用户访问；删除该目录即可安全清空结果，macOS 也可回收这些文件。

磁盘读写只在可取消的后台图表任务中执行，不占用 UI 或内存缓存锁。命中后校验键、尺寸和内容完整性，再交给内存缓存，跳过 WebKit 启动。损坏条目移除后重建，存储不可用或空间不足不会阻止正常渲染。共享策略 `diagram.disk_cache_bytes` 约束已存文件字节，临时写入和多进程并发可短暂超过目标。最近使用时间驱动淘汰，清理只保留有界候选窗口，必要时再次扫描。只持久化成功结果。既有命中计数仍只覆盖两层内存缓存，不代表磁盘命中或实际避免的引擎工作。

`CacheActivity` 在消费者查找入口记录命中、未命中和等待中。服务层图片缓存与视图层预览缓存分别计数；首次不存在的键也记为未命中。新结果发布、资源固定、驻留检查和回收不计入查找。预览的等待中表示先前请求已排队，不加入命中率分母；预览错误对象的复用也属于驻留命中。服务层驻留命中不保证批次的剩余额度允许使用该图片，不能直接当作避免渲染的次数。

本地计数在进程内累计，不保存正文或缓存键。沿用现有统计授权的 `resource_sample` 仅报告采样区间增量；重新启用或重新启动采样时建立新基线，不补发停用期间的查找。每层命中率分别为 `hits / (hits + misses)`，没有查找时不报告比例；两层分母不同，不能相加计算统一命中率。

运行 `cargo bench -p glim-services --bench diagram_cache --locked` 可比较准备好 PNG 的首次未命中加发布与驻留查找，并核对键隔离、资源固定、共享压力回收、重建及完整释放。PNG 编码与内容对照在计时之外，测量不包含图表引擎、WebView、UI 绘制或进程内存峰值。原始样本及环境／源码信息保存在仓库外。
