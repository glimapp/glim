# Windows 功能支持清单

对照版本为 macOS v0.2.27。Windows 本地版位于 `codex/windows-port` 分支，嵌入式网页使用 Microsoft Edge WebView2。表中的“已验证”只覆盖该行列出的操作。

| 功能 | Windows 支持情况 | 使用范围与待验证项 |
| --- | --- | --- |
| 工作区与窗口 | 常用操作已验证 | 标签与窗口按钮同排。可切换侧栏、打开搜索、切换预览与原文。开始菜单快捷方式和运行中的任务栏图标已核对，固定到任务栏后的表现待验收。 |
| 工作区内容搜索 | 已验证 | 在工作区搜索中输入只出现在 Markdown 正文里的词，可找到对应文档。 |
| Markdown 阅读 | 常用排版已验证 | 标题、表格、任务列表、公式和 Mermaid 已显示。复杂图表、所有扩展语法和全部主题组合尚未逐项验收。 |
| Markdown 导出 | HTML 与 PDF 已接通 | HTML 可内嵌图片与图表。PDF 使用 WebView2 分成 A4 页面，工具栏和命令行共用导出流程。 |
| HTML 阅读与编辑 | 已验证 | 可切换原文与预览，修改后能看到新正文。外部样式、脚本、相对图片和带锚点的本地链接已验证，涵盖中文文件名和带空格的目录。 |
| HTML 文件内查找 | 已接通并验证匹配 | 从预览工具栏打开查找，可搜索渲染后的正文，支持上一项、下一项和区分大小写。依赖运行时提供 WebView2 Find API。 |
| 路径与本地化 | 部分支持 | 导航显示 Windows 路径，资源管理器使用平台名称。网络共享、长路径、复制绝对路径和所有设置页文案尚未逐项验收。 |
| PDF 阅读 | 部分支持 | 使用 WebView2 内嵌 PDF。Glim 的 PDF 专用查找与重新加载仍需实现，密码文档和系统打印待验证。 |
| 图片 | 部分支持 | 常见图片可走内嵌预览；缩略图与 Markdown 插图使用独立处理路径。相册播放、OCR、多页 TIFF 和特殊编码仍需分别核验。 |
| Word、表格与演示文稿 | 部分支持 | 已有转换后的 Word 阅读路径。工作簿分页、PowerPoint 版式和 iWork 文档缺少与 Mac 对应的 Windows 预览。 |
| 音视频 | 基础播放 | 播放取决于 WebView2 和系统解码器。目录队列、随机播放、播放位置恢复及不同编码组合待补齐。 |
| 数据、源码、压缩包与电子书 | 共用 Rust 阅读器 | CSV、JSON、SQLite、源码编辑、归档与书籍具备共用实现。格式识别、阅读、保存或解压的每一步还需在 Windows 分别验证。 |
| 字体及其他专业格式 | 按格式区分 | CoreText 字体集合和字形预览缺少 Windows 后端。XMind、draw.io、模型和地图等共用阅读器待专项验收。 |
| 系统集成 | 部分支持 | Windows 本地安装和启动可用。默认文件关联、应用打印、自动更新和终端集成仍有缺口。 |

macOS 的逐格式说明见[文件格式与兼容范围](file-format-support.zh-CN.md)。Git 工作区功能暂不纳入 Windows 对齐范围。
