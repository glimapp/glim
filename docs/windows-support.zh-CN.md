# Windows 功能支持清单

对照版本为 macOS v0.2.27。Windows 本地版位于 `codex/windows-port` 分支，嵌入式网页使用 Microsoft Edge WebView2。表中的“已验证”只覆盖该行列出的操作。

| 功能 | Windows 支持情况 | 使用范围与待验证项 |
| --- | --- | --- |
| 工作区与窗口 | 常用操作已验证 | 标签与窗口按钮同排。侧栏展开时，Glim 品牌名与「主页」文字左对齐。可切换侧栏、打开搜索、切换预览与原文。开始菜单快捷方式和运行中的任务栏图标已核对，固定到任务栏后的表现待验收。 |
| 工作区内容搜索 | 已验证 | 在工作区搜索中输入只出现在 Markdown 正文里的词，可找到对应文档。 |
| Markdown 阅读 | 常用排版已验证 | 标题、表格、任务列表、公式和 Mermaid 已显示。复杂图表、所有扩展语法和全部主题组合尚未逐项验收。 |
| Markdown 导出 | HTML 与 PDF 已接通 | 独立 HTML 可内嵌本地图片、通过 HTTP 下载的 PNG 和图表。PDF 使用 WebView2 分成 A4 页面，工具栏和命令行共用导出流程。 |
| HTML 阅读与编辑 | 已验证 | 从文件树打开本地 HTML，阅读区可见标题、正文和相对路径图片。可切换原文与预览，修改后能看到新正文。外部样式、脚本、相对图片和带锚点的本地链接已验证，涵盖中文文件名和带空格的目录。 |
| HTML 文件内查找 | 已接通并验证匹配 | 从预览工具栏打开查找，可搜索渲染后的正文，支持上一项、下一项和区分大小写。依赖运行时提供 WebView2 Find API。 |
| 路径与本地化 | 部分支持 | 导航显示 Windows 路径，资源管理器使用平台名称。网络共享、长路径、复制绝对路径和所有设置页文案尚未逐项验收。 |
| PDF 阅读 | 图文、纯图片页、查找与外部更新已验证 | 从文件树打开 17 页中文 PDF，首页标题、正文和表格可见。两页纯图片 PDF 滚动后可看到不同的页图。Glim 工具栏的查找可定位至 17 页文档的末页，并跳转到下一处匹配。外部程序替换文件后，打开的标签可从 1 页刷新为 3 页；写入不完整的 PDF 时保留上一次可读版本。密码文档、刷新后的页码与缩放位置、系统打印待验收。 |
| 图片 | 普通 PNG 已验证 | 从文件树打开中文目录里带空格的 PNG，可在图片标签中看到图像并切换标签。使用系统图像解码器和 Glim 画布。动画 PNG、相册播放、OCR、多页 TIFF 和其他编码待验收。 |
| Word、Excel、PowerPoint | 依赖系统预览器 | 已从文件树核对本机 WPS 在 Glim 阅读区显示的 DOCX 中文封面、XLSX 单元格文字和 PPTX 标题及图片。其他机器需要注册对应的资源管理器预览处理程序。复杂排版、密码文档和 iWork 文档待验收。 |
| 音视频 | 基础播放 | 播放取决于 WebView2 和系统解码器。目录队列、随机播放、播放位置恢复及不同编码组合待补齐。 |
| 数据、源码、压缩包与电子书 | 共用 Rust 阅读器 | CSV、JSON、SQLite、源码编辑、归档与书籍具备共用实现。格式识别、阅读、保存或解压的每一步还需在 Windows 分别验证。 |
| 字体及其他专业格式 | 按格式区分 | 字体可使用系统注册的预览器。字体集合、自定义样张与字形列表待验收，XMind、draw.io、模型和地图等共用阅读器待专项验收。 |
| 系统集成 | 部分支持 | Windows 本地安装和启动可用。默认文件关联、应用打印、自动更新和终端集成仍有缺口。 |
| 命令行打开与预览 | 已验证 | `Glim.exe --cli open PATH` 在 Glim 打开文件，`Glim.exe --cli preview FILE.md` 调用系统默认浏览器显示独立 HTML。已用带中文和空格的文件名分别验证 Glim 和 Edge。 |

macOS 的逐格式说明见[文件格式与兼容范围](file-format-support.zh-CN.md)。Git 工作区功能暂不纳入 Windows 对齐范围。
