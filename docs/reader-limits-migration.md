# 大文件处理：当前实现与约束

本文供阅读器维护者参考。普通用户遇到大文件时，先看[常见问题](faq.zh-CN.md)和[格式兼容范围](file-format-support.zh-CN.md)。数值清单由配置生成，本文只说明处理路径和未完成部分。

文件总大小不作为拒绝受支持文件的理由；通过流式、分页、按需解码及完整源后备控制工作内存。

## 配置

唯一入口为 [reader-limits.json](../assets/reader-limits.json)，完整数值、单位及效果见自动生成的双语清单。

全部条目含中文行为说明；生成器生成[英文清单](reader-limits.md)及[中文清单](reader-limits.zh-CN.md)。修改策略后运行 `python3 scripts/generate-reader-limits.py --docs`。

## 已实现

- UTF-8 可编辑分页；固定缓冲复制、原子保存、取消保存；刷新保留当前页和未改变的编辑器。
- 压缩流按需解码及滚动缓存，取消后重建解码器；容器目录、可执行文件、NumPy、safetensors 提供分页报告或完整源后备。
- XLSX 流式建立磁盘 SQLite 单元格索引，保留全部工作表、坐标、缓存值和公式；XLS 使用 Quick Look，默认按行列页生成带样式、合并与缓存值的 Quick Look 展示副本，完整索引保留在内部，不提供独立单元格数据模式；不重算公式，不复制图表及绘图。分页使用现有 SQLite 行列策略与 IO 工作预算，不限制工作簿总行数或大小。
- 电子书保留章节导航；复杂章节或包元数据提供完整文本／十六进制成员分页。资源按需解压，插图使用临时文件缩略图；标题摘要可查看全文。
- GPX/KML 坐标分页；图表与公式按可见区域自动排队并分批渲染，缓存按工作预算淘汰，不要求用户手动切换图表页；超出单块结构化预算时保留完整源内容。
- CSV 完整值和 SQLite 完整单元格／结构按窗口访问；大型文本对话框使用磁盘分页。
- 图片串行可取消解码、QOI 流式采样、GIF 工作缓冲；保留原始逻辑尺寸及完整字节入口。音频封面提供完整资源入口。
- 远程图片流式落盘；SVG 流式处理；XMind、OBJ/STL/BDF 复杂投影回退完整源分页。
- MKV 流读取及磁盘时间戳索引、fragmented MP4 输出；字体、播放列表、书签和会话总量门槛移除。

## 实现约束与未验证交互

图片采用预算内缩放预览，并非原分辨率分块解码。ImageIO/WebKit/Quick Look 的内部临时分配、SQLite 表达式求值和 ZIP 中央目录索引仍受平台／库实现约束。ZIP member 按需解码支持 Stored/Deflate，CRC 与长度在解码到末尾时校验。部分索引／报告需准备完成后才能显示首屏。
