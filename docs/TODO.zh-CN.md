# 待办与验收缺口

[English](TODO.md) · **简体中文** · [文档目录](README.zh-CN.md)

Glim 当前已覆盖办公、阅读、多媒体、数据和开发等[使用场景](topics.zh-CN.md)。这里说明哪些地方还需要完善，方便你判断是否适合手头的工作。候选工作不代表发版时间承诺。

## 架构与性能待办

约束：保留 `app → services → core` 三层结构；阅读器优先使用普通模块。独立 crate 需要真实的版本、依赖隔离或复用需求。新增格式和场景继续组合既有能力，外部插件安装与动态加载留待以后。

| 方向 | 当前已落实 | 完成条件 |
| --- | --- | --- |
| 阅读器模块化 | 生命周期与能力契约、集中装配、共享编辑会话；OPML、图结构和 JSON 展示通过纯数据与宿主注入隔离 | 其余阅读器也有明确、可验证的准备／展示／宿主边界，不能由少数模块推断全部可独立迁出 |
| 资源管理 | 共享资源池和任务准入；文本／十六进制页、表格、结构树、PNG／GIF 的主要缓冲预留；多类视图支持隐藏释放及重建 | 可控工作缓冲在分配前统一准入，跨活动阅读器的压力回收可用；明确并实测框架及辅助进程的覆盖边界 |
| 增量处理与测量 | Markdown 普通单行文字编辑复用块；输入路径减少全文复制；解析、像素、结构树、源码窗口及图片缓存有测量入口；两层图表缓存分别计数 | 真实工作空间及各类阅读器有可重复的首屏／交互／资源测量和前后对照，性能结论限定到实测范围 |

### 阅读器模块化

- [ ] **M1：其余阅读器边界。** CSV／地理表格、SQLite 和书籍展示已通过显式数据／宿主契约和语义请求隔离。继续审视媒体、压缩包、分页、源码／排版和原生适配模块，分离准备、持久状态、展示和宿主操作。验收：展示代码不承担文件 I/O 或后台任务编排；必要的应用依赖由装配层注入，架构检查覆盖实际边界。
- [ ] **M2：生命周期契约验收。** 覆盖激活／隐藏、刷新、取消、失败重试、关闭及跨窗口移动。验收：保留原编辑会话、撤销和未保存状态；过期任务不能覆盖新版本，生产者与消费者的代表性数据契约实际运行通过。

### 资源覆盖与压力恢复

- [ ] **R1：剩余可控分配准入。** 结构化交互图最终输出、遍历数组及缩略图几何已在分配前准入，输入解析与图布局仍未完成。补齐解析器 `Value`／JSON5 工作区、书籍 HTML／元数据、编码预览／SVG 中间缓冲，以及 SQLite／地理解析的可控暂存。验收：分配与扩容峰值在预算内，所有者跨工作线程和发布交接持续持有额度；清除工作缓冲绕过准入的 `track`／`resize` 路径。
- [ ] **R2：原生与辅助进程资源。** 补齐原生准备、转换、复制／OCR 的可控工作集，区分 ImageIO、WebKit、Quick Look、GPUI 图集、SQLite 引擎及辅助进程的不透明分配。验收：有实际系统内存观测和压力下降级／恢复证据，不把应用记账称作进程内存硬上限。
- [ ] **R3：跨活动阅读器回收。** 统一可重建资源的压力释放、重试与恢复，处理多个窗口同时工作及单个大操作。验收：有限工作内存下仍能前进，未保存正文和必要交互状态受保护；取消中的工作退出前不提前释放其占用，返回阅读器可恢复可读内容。

### 增量处理与性能证据

- [ ] **P1：剩余全文工作。** 缩略图更新已共享 Rope 正文及未变化几何块，只重算变化行；冻结基线基准和真实窗口脚本覆盖这条路径。继续测量并减少 Markdown 块克隆和单个大块布局成本，在有收益依据时扩展结构编辑的块复用。验收：与完整解析语义一致，引用、列表、围栏和源码映射正确，安全回退保留；报告包含规模、修改位置及延迟分位数。
- [ ] **P2：端到端场景。** 将测量扩展到真实工作空间的保存协调、分页、异步文档／数据预览、书籍、图表和原生阅读器。验收：首个可读内容、首屏、滚动／输入阻塞与任务排队／准备分别计时，检测真实内容就绪，保存固定夹具、机器／工具链／源码信息及前后原始样本。
- [ ] **P3：真实缓存收益。** 在文档打开、重复访问、滚出／返回和资源压力下实测图片缓存与展示缓存。验收：分别报告命中、未命中、等待中、回收和实际避免的准备工作；当前缓存基准只覆盖准备好的 PNG 查找／发布，不能证明引擎或首屏提速。
- [ ] **P4：运行验收。** 执行相关回归和 Apple Silicon／Intel 实机交互，覆盖多窗口和资源压力。编译通过不能替代这些验收；未运行项须继续保留。

## 各场景仍需完善

| 场景 | 当前差距 |
| --- | --- |
| 办公 | 复杂排版、图表与嵌入对象还原，公式重算，开放文档格式的完整阅读 |
| 阅读 | EPUB 出版者样式及固定版式还原 |
| 继续工作 | 通用滚动、光标和媒体时间恢复；草稿恢复可靠性 |
| 图表 | PlantUML Salt/Chen 的完整方言；外部资源兼容仍受限制 |
| 专业文件 | GIS 地图和 3D 交互未提供；GGUF/ONNX/NPZ 阅读器尚待实现 |
| 安装 | Developer ID 签名与 Apple 公证，需要证书和凭据 |

## 仍需覆盖的验收

- Apple Silicon 与 Intel 实机界面交互、图形环境／驱动和可访问性。
- 真实 GitHub 正式版本升级、管理员安装目录、多实例、取消授权、替换中断及恢复。
- 原生文档预览器：密码／坏文件、办公文档包、媒体编码、字体集合与可访问性。
- 活跃 SQLite/WAL 源、源状态变动拒绝、孤立 sidecar 和原库保持不变。
- Finder 冷／热启动打开、重复／跨窗口激活、文件关联更改／恢复及原生视图释放。
- 多窗口保存冲突和并发文件操作、监听刷新、大文件阅读器及各平台手势。

已有 Rust／原生／隔离安装测试有帮助，但不能证明以上全部场景。验证修改时运行相关检查，发布说明只报告实际覆盖。

## 当前范围外

非 macOS 平台不属于产品范围；既有公开附件继续保留。

LSP、外部插件安装与动态加载不属于当前产品范围。内部模块化继续遵循上述依赖边界。

参见[格式](file-format-support.zh-CN.md)、[架构](architecture.zh-CN.md)、[更新](auto-update-design.zh-CN.md)和[发布流程](releasing.zh-CN.md)。
